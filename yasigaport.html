Projects

Sensor based waste management

My project is a waste segregation system based on sensors. It uses different types of sensors to automatically identify and separate waste into categories such as biodegradable, recyclable, and non-recyclable. For example, infrared sensors can detect moisture to distinguish organic waste, while metal sensors identify metallic items. Once detected, the system directs the waste into the correct bin using simple mechanical or automated mechanisms. This approach reduces human effort, improves efficiency, and supports eco‑friendly waste management by ensuring proper disposal and recycling.

Automated bus scheduling

My project is an automated bus scheduling system for college. It uses software and simple algorithms to plan bus routes and timings based on student needs, class schedules, and bus capacity. The system reduces manual effort by automatically assigning buses to routes, optimizing travel time, and ensuring efficient use of resources. With features like real‑time updates and easy adjustments, it helps improve punctuality, minimize waiting time, and provide a smoother transportation experience for students and staff.

Automated accident alert system

My project is an automated accident alert system in buses. It uses sensors to detect sudden impacts, unusual vibrations, or emergency conditions inside the vehicle. When an accident occurs, the system automatically sends an alert message with details such as bus location and time to nearby hospitals, police stations, and college authorities. This ensures quick response, reduces delays in rescue operations, and improves passenger safety. By combining sensor technology with communication modules, the system provides a reliable way to handle emergencies efficiently.
